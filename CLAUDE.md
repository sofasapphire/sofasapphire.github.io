## Структура: маленькие файлы по смыслу

Правило для любого нового блока, страницы или записи:

- **Тексты блока** — отдельный JSON: `src/data/pages/<страница>/<блок>.json`;
  общий для нескольких страниц — `src/data/blocks/<блок>.json`. Не в разметке.
- **Типы и фото страницы** — `src/data/pages/<страница>/index.ts` (реэкспорт JSON + импорт картинок).
- **Вёрстка** — `src/components/<страница>/<Блок>.astro`, только разметка и scoped-стили.
- **Логика в браузере** — `src/scripts/<функция>.ts`, в компоненте только `import`.
- **Коллекция записей** (много однотипных записей с фото) — схема в `src/content/schemas/<коллекция>.ts`,
  записи — `src/content/<коллекция>/<slug>/index.md` + фото рядом, выборка — `src/lib/<коллекция>.ts`.
- **Раздел админки** — `public/admin/collections/<раздел>.yml` + `<link>` в `admin/index.html`.
  Поля держать в синхроне со схемой/JSON.
- Файл разрастается больше ~150–200 строк или смешивает разные задачи — разбить.

## Соглашения

- Виды съёмки и съёмки меняются из админки — вёрстка не должна зависеть от их числа и названий.
- Удалённый вид не ломает сборку: его съёмки скрываются с предупреждением (`src/lib/shoots.ts`).
- Цвета — только `var(--color-*)` из `tokens.css`. Палитра по умолчанию — B «Ирис и лаванда».
- Стили — scoped `<style>` в компоненте; глобальное — только в `base.css`.
- Импорты через `@/`. Slug-и — латиница, нижний регистр, дефисы.
- Анимация появления: атрибут `data-reveal` (или `data-reveal="fade"` для фото) — стили в
  `styles/motion.css`, логика в `scripts/reveal.ts`. Новым блокам ставить его же.
- Многострочный текст из админки — `components/ui/Lines.astro`, абзацы — `components/ui/Paragraphs.astro`.
- Пропуски «___» в текстах — через `components/ui/Fill.astro` (подсвечиваются жёлтым, пока не заполнены).
- Фото страниц из JSON — через `imageFinder` из `src/lib/images.ts` (glob в `data/pages/<страница>/index.ts`).
- Кавычки в текстах — ёлочки «».
- Перед сдачей: `npm run check` и `npm run build` без ошибок.
- Dev-сервер после переноса файлов/больших правок CSS — перезапускать с очисткой
  `node_modules/.vite` (иначе браузер показывает старые стили или старые пути к фото).
